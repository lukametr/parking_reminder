ქართულად

აპი თბილისის ფასიან ზონალურ პარკინგზე შეხსენებას აკეთებს (წუთებში ბილინგი; დროს არ ვითვლით). ანგარიში არ გვჭირდება.

რა მონაცემს ვიღებთ / ვაგროვებთ (WHAT)

  • ზუსტი ლოკაცია (GPS / precise location), მათ შორის ფონში — როცა აპი ჩაკეცილია, ეკრანი გამორთულია ან აპი არ არის გახსნილი („ყოველთვის“ / Allow all the time), თუ ჩართულია მონიტორინგი.

რატომ (WHY)

  • რომ ამოვიცნოთ გაჩერება ფასიან ლოტთან (≈5–8 მ), გაჩვენოთ ლოტის ნომერი და შეგახსენოთ ოფიციალურ აპში (ge.msda.parking / MSDA) პარკირების ჩართვა ან გამორთვა.

როგორ ვიყენებთ (HOW)

  • კოორდინატი მუშავდება ტელეფონზე (on-device) foreground სერვისში (მუდმივი შეტყობინება „პარკინგის მონიტორინგი ჩართულია“). ვადარებთ Firestore კოლექციას parkings.
  • GPS ტრეკს სერვერზე არ ვტვირთავთ. სესია ლოკალურია.
  • ლოკაციას არ ვყიდით და რეკლამის პროფილირებისთვის / პერსონალიზებული რეკლამისთვის არ ვიყენებთ.

აპში სრულეკრანიანი Prominent Disclosure (გაგრძელება / უარყოფა) ჩანს სანამ სისტემის ლოკაციის ნებართვას ვითხოვთ.

სხვა მონაცემები

  • რეკლამა (Google AdMob) — ბანერი და interstitial. Google-მა შეიძლება გამოიყენოს სარეკლამო ID. ლოკაციას რეკლამისთვის ჩვენ არ ვაწვდით.
  • კრეშის ლოგები (Firebase Crashlytics) — მოდელი, OS, stack trace.
  • Firebase Remote Config — ფონის სურათის URL / რეკლამის დროშები.
  • Maps / Places — თუ გახსნით სერვისების რუკას, Google Places იღებს მოთხოვნის მდებარეობას ახლომდებარე ობიექტებისთვის (მხოლოდ თანხმობისა და ნებართვის შემდეგ).
  • SOS — 112 / დაზღვევა ხსნის აკრეფას. ზარს ჩვენ არ ვაკეთებთ და ნომერს არ ვინახავთ.

English

This app reminds Tbilisi drivers about paid zonal parking (billed per minute; we do not run a countdown). No login.

  • WHAT: Precise GPS location, including in the background when the app is closed or not on screen (“Allow all the time”), while monitoring is on.
  • WHY: Detect stops near paid lots (~5–8 m), show the lot number, and remind you to start/stop payment in the official MSDA app (ge.msda.parking).
  • HOW: Processed on-device in a foreground service with a persistent notification. We do not upload GPS tracks, do not sell location, and do not use location for ads profiling. A full-screen in-app Prominent Disclosure (Continue / Decline) appears before any system location permission.
  • Ads (AdMob): banner and interstitial; advertising ID per Google policy. We do not feed location to ads.
  • Crash logs (Firebase Crashlytics) to fix bugs. Remote Config for UI/ad flags. Places only after disclosure + permission. SOS only opens the dialer.
