ქართულად

აპი თბილისის ფასიან ზონალურ პარკინგზე შეხსენებას აკეთებს. ანგარიში არ გვჭირდება.

რა მონაცემს ვაგროვებთ

  • ზუსტი ლოკაცია (GPS), მათ შორის ფონში და გადატვირთვის შემდეგ, თუ ჩართულია მონიტორინგი. კოორდინატი მუშავდება ტელეფონზე foreground სერვისში (მუდმივი შეტყობინება). ვადარებთ Firestore კოლექციას parkings (~15 მ). გაჩერებაზე გეკითხებით ოფიციალურ აპში (ge.msda.parking) პარკირების ჩართვას; გასვლაზე — გამორთვას. GPS ტრეკს სერვერზე არ ვტვირთავთ. სესია ლოკალურია. ლოკაციას რეკლამის პროფილისთვის არ ვიყენებთ და არ ვყიდით.
  • რეკლამა (Google AdMob) — ბანერი და interstitial. Google-მა შეიძლება გამოიყენოს სარეკლამო ID / მოწყობილობის სიგნალები თავისი პოლიტიკით. პერსონალიზაციის opt-out — ტელეფონის პარამეტრებში.
  • კრეშის ლოგები (Firebase Crashlytics) — მოდელი, OS, stack trace, რომ გავასწოროთ შეცდომები.
  • Firebase Remote Config — ფონის სურათის URL / რეკლამის დროშები.
  • Maps / Places — თუ გახსნით სერვისების რუკას, Google Places იღებს მოთხოვნის მდებარეობას ახლომდებარე ობიექტებისთვის.
  • SOS — 112 / დაზღვევა ხსნის აკრეფას. ზარს ჩვენ არ ვაკეთებთ და ნომერს არ ვინახავთ.

ნებართვები

  • Fine / background location
  • Physical activity (GPS სიზუსტე გაჩერებისას; მოძრაობისას ენერგიის დაზოგვა)
  • Notifications · Internet

უარი „ყოველთვის“-ზე: ფონური შეხსენება არ იმუშავებს. მონაცემებს არ ვყიდით.

English

This app reminds Tbilisi drivers about paid zonal parking (billed per minute; we do not run a countdown). No login.

  • Precise location, including in the background while a visible foreground service runs, to detect nearby parking lots and remind you to start or stop payment in the official MSDA app. Location is processed on-device. We do not upload GPS tracks or sell location. Sessions stay on the phone.
  • Ads (AdMob): banner and interstitial; advertising ID per Google policy.
  • Crash logs (Firebase Crashlytics) to fix bugs.
  • Remote Config for UI/ad flags. Places queries if you open service maps. SOS only opens the dialer.
